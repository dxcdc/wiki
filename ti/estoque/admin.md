# 🛠️ Estoque TI — Administradores de Sistema

Configurações gerais e regras de permissões de banco de dados do sistema de Estoque de TI.

---

## 📖 Diretrizes do Administrador

### 1. Permissões de Acesso
* Garanta que apenas a equipe técnica credenciada tenha permissão de Escrita (Edição) no estoque.

### 2. Parametrização de Categorias
* Cadastro de novos tipos de hardware (ex: Servidores, Placas, Roteadores) no sistema.
