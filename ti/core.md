# ⚙️ Core (Central de TI)

O **Core** é a plataforma interna de centralização de ferramentas administrativas, painéis e controles de infraestrutura de TI do **Centro de Desenvolvimento e Cidadania (CDC)**. Ela permite o monitoramento de servidores, recursos digitais e integrações corporativas.
