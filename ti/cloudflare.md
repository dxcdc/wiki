# 🌐 Cloudflare

O **Cloudflare** é a plataforma de infraestrutura web utilizada pelo **Centro de Desenvolvimento e Cidadania (CDC)** para gerenciamento de zonas de DNS, segurança de borda (proteção WAF e anti-DDoS), distribuição de conteúdo (CDN) e provisionamento de certificados de criptografia SSL/TLS.
