# 📊 ONGSYS (ERP Financeiro)

O **ONGSYS** é o sistema integrado de gestão (ERP) oficial do **Centro de Desenvolvimento e Cidadania (CDC)**. Ele é uma plataforma focada no terceiro setor, utilizada para controle contábil, financeiro, conciliação bancária, faturamento e prestação de contas de convênios.
