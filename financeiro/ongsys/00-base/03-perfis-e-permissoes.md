# Perfis e Permissões

Nem todos os colaboradores do **CDC** visualizam as mesmas telas ou realizam as mesmas ações no ONGSYS. O sistema utiliza uma estrutura de perfis de acesso baseada nas responsabilidades de cada cargo.

## Regras Importantes
* **Privilégio Mínimo:** Você só terá acesso às ferramentas necessárias para executar suas tarefas funcionais.
* **Separamento de Papéis:** Um solicitante operacional não pode aprovar a própria requisição.
* **Ocultação de Opções:** Se um botão ou menu não aparecer na sua tela, isso se deve ao seu perfil de acesso, não sendo um erro do sistema.

> **Não faça: Compartilhamento de Perfis**
> Nunca solicite ou use o login de um colega para executar um procedimento que você não tem permissão para realizar. Se precisar de acessos adicionais, faça a solicitação formal.

> **Atenção:** Confirmar a matriz de perfis e permissões da CDC no sistema para garantir que os nomes dos perfis batam com os cadastrados no banco de dados.
