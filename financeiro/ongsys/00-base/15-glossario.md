# Glossário de Termos

Lista de termos e siglas comumente utilizados no ERP ONGSYS e nos processos do **CDC**.

## Termos Comuns

* **ERP:** *Enterprise Resource Planning* (Sistema Integrado de Gestão).
* **Centro de Custo:** Código que agrupa despesas e receitas de um projeto ou departamento.
* **Rubrica:** Classificação orçamentária do tipo de despesa (alimentação, passagens, etc.).
* **Alçada:** Limite de valor que define qual cargo deve aprovar uma solicitação.
* **Conciliação:** Comparação dos dados do sistema com os dados do extrato bancário.
* **Competência:** O período (mês/ano) de ocorrência real da despesa ou receita.
* **Vencimento:** Data limite para pagamento de uma obrigação financeira.
